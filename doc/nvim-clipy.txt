1. Introduction                                    *nvim-clipy-introduction*

nvim-clipy talks directly to the `clipy` daemon's Unix socket (see the
clipy-rust project) using `vim.uv`, so it needs the daemon running. No
`clipy` binary is required by the plugin itself, only the daemon.

==============================================================================
2. Installation                                  *nvim-clipy-installation*

The `clipy` daemon is published on crates.io and installs via cargo:
>
    cargo install clipy
<
Then start it (in the background, or under a process supervisor of your
choice):
>
    clipy watch > /tmp/clipy.log 2>&1 &
<

With lazy.nvim, from GitHub:
>lua
    -- lua/plugins/nvim-clipy.lua
    return {
      {
        "c12i/nvim-clipy",
        config = function()
          require("nvim-clipy").setup()
        end,
      },
    }
<

==============================================================================
3. Setup                                                  *nvim-clipy-setup*

>lua
    require("nvim-clipy").setup({
      -- defaults shown
      socket_path = vim.fn.expand("~/Library/Application Support/clipy-rust/clipy.sock"),
      history_limit = 30,
    })
<

==============================================================================
4. Commands                                            *nvim-clipy-commands*

    :ClipyList                     List recent clipboard history entries.
    :ClipyShow {id}                Show an entry's full content in a float.
    :ClipyCopy {id}                Copy an entry back to the clipboard.
    :ClipyDelete {id}               Delete one entry.
    :ClipyClear                    Delete all history.
    :ClipyStatus                   Show daemon status.
    :ClipyKill                     Stop the running daemon.
    :ClipyPick                     Pick an entry via Telescope, with a
                                     content preview (requires telescope.nvim).
                                     Also available as `:Telescope nvim-clipy`
                                     once the extension is loaded with
                                     `require("telescope").load_extension("nvim-clipy")`.

`{id}` accepts a unique prefix, same as the `clipy` CLI.

==============================================================================
5. Keymaps                                              *nvim-clipy-keymaps*

No default keymaps are set. A suggested bind for `:ClipyPick`:
>lua
    vim.keymap.set("n", "<leader>sy", function()
      require("nvim-clipy.telescope").pick()
    end, { desc = "Clipboard history" })
<
Or, if managing keymaps through lazy.nvim's `keys` spec (lazy-loads the
plugin on first press instead of at startup):
>lua
    {
      "c12i/nvim-clipy",
      keys = {
        {
          "<leader>sy",
          function() require("nvim-clipy.telescope").pick() end,
          desc = "Clipboard history",
        },
      },
      config = function()
        require("nvim-clipy").setup()
      end,
    }
<

==============================================================================
6. Lua API                                                  *nvim-clipy-api*

>lua
    require("nvim-clipy").setup(opts)
    require("nvim-clipy").list()
    require("nvim-clipy").show(id)
    require("nvim-clipy").copy(id)
    require("nvim-clipy").delete(id)
    require("nvim-clipy").clear()
    require("nvim-clipy").status()
    require("nvim-clipy").kill()
    require("nvim-clipy").fetch(opts, callback) -- opts = { limit, query }
<

`fetch()` is async: `callback(entries)` fires once the daemon responds,
where each entry is `{ id, content, created_at, updated_at }`. All other
functions are fire-and-forget and report errors via |vim.notify()|.
